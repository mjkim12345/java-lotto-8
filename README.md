# 로또
## 프로젝트 개요
### 1.1 프로젝트 이름
- 로또
### 1.2 프로젝트 설명
- 로또 구입 금액과 당첨 번호를 입력 받아 당첨 내역을 출력하는 로또 발매기 프로젝트
---
## 2. 구현할 기능
### 2.1 입력 문구 출력 기능
- 사용자에게 `구입금액을 입력해 주세요.`라는 문구를 출력한다.
- 사용자에게 `당첨 번호를 입력해 주세요.`라는 문구를 출력한다.
- 사용자에게 `보너스 번호를 입력해 주세요`라는 문구를 출력한다.
### 2.2 사용자 입력 기능
- 사용자 입력은 `camp.nextstep.edu.missionutils.Console`의 `readLine()을` 활용한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리 한다.
#### 2.2.1 로또 구입 금액 입력 기능
- 구입 금액은 `1,000원` 단위로 입력 받는다.
- `1,000원`으로 나누어 떨어지지 않을 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 구입 금액은 1,000원 단위로 입력해야 합니다.`
- 구입 금액이 숫자가 아닌 값이 입력될 경우 에외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 구입 금액은 숫자만 입력해야 합니다.`
- 구입 금액이 `0원` 이하일 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 구입 금액은 0을 초과해야 합니다.`
#### 2.2.2 당첨 번호 입력 기능
- 당첨 번호는 중복되지 않는 숫자 6개를 쉼표(,)를 기준으로 받는다.
- 쉼표(,)를 기준으로 분할 하였을 때 리스트의 길이가 6이 아닐 시 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 당첨 번호는 숫자 6개를 입력 해야 합니다.`
- 당첨 번호가 숫자가 아닌 값이 입력될 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 당첨 번호는 숫자만 입력해야 합니다.`
- 1 ~ 45 사이의 숫자가 아닌 값이 입력될 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 당첨 번호는 1 ~ 45 사이의 수만 입력 해야 합니다.`
- 입력 된 값들에 중복이 있을 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 당첨 번호는 중복되지 않은 값들만 입력 해야 합니다.`
#### 2.2.3 보너스 번호 입력 기능
- 보너스 번호는 당첨 번호와 중복되지 않은 1 ~ 45 사이의 수를 입력 받는다.
- 숫자가 아닌 값이 입력될 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 보너스 번호는 숫자만 입력해야 합니다.`
- 1 ~ 45 사이의 숫자가 아닌 값이 입력될 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 보너스 번호는 1 ~ 45 사이의 숫자만 입력해야 합니다.`
- 당첨 번호와 중복되는 숫자가 입력될 경우 예외 처리 후 입력을 다시 받는다.
  - 에러 메시지 : `[ERROR] 보너스 번호는 당첨 번호와 중복되지 않은 값을 입력해야 합니다.`
### 2.3 로또 발행 기능
- 1,000원에 1개씩 구입 금액에 맞춰 로또 n개를 발행한다.
  - 예시 : 구입 금액이 8,000원 로또 8개 발행
- 1개의 로또를 발행 할 때 중복되지 않은 1 ~ 45 사이의 숫자 6개를 발행한다.
  - 예시 : [1,5,7,32,35,40]
### 2.4 당첨 내역 계산 기능
- 각각 발행된 로또와 입력 받은 당첨 번호를 비교해 일치하는 개수를 계산한다.
- 당첨 기준에 따라 당첨 금액을 계산하고 저장한다.
  - 1등 : 6개 번호 일치 / 2,000,000,000원
  - 2등 : 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등 : 5개 번호 일치 / 1,500,000원
  - 4등 : 4개 번호 일치 / 50,000원
  - 5등 : 3개 번호 일치 / 5,000원
### 2.5 총 수익률 계산 기능
- 구입 금액과 당첨 금액을 비교해 수익률을 계산한다.
- 수익률은 소수점 둘째 자리에서 반올림 한다.
### 2.6 출력 기능
- 구매한 로또 수량과 발행한 로또 번호들을 출려한다.
  - 오름차순으로 로또 숫자들을 나열한다.
  - 예시 : <br>
> ```
> 8개를 구매했습니다.
> [8, 21, 23, 41, 42, 43]
> [3, 5, 11, 16, 32, 38]
> [7, 11, 16, 35, 36, 44]
> [1, 8, 11, 31, 41, 42]
> [13, 14, 16, 38, 42, 45] 
> [7, 11, 30, 40, 42, 43]
> [2, 13, 22, 32, 38, 45]
> [1, 3, 5, 14, 22, 45]
> ```
- 당첨 통계를 출력한다.
  - 예시 `당첨 통계`
- 구분선 `---`를 출력한다.
- 금액과 함께 당첨 내역을 출력한다.
  - 예시 : <br>
> ```
> 3개 일치 (5,000원) - 1개
> 4개 일치 (50,000원) - 0개
> 5개 일치 (1,500,000원) - 0개
> 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
> 6개 일치 (2,000,000,000원) - 0개
> ```
- 총 수익률을 출력한다.
  - 예시 : `총 수익률은 62.5%입니다.`
